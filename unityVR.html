VR Proje Kurulumu

Meta Quest (1) cihazı hazırlamak ve meta kullanıcısı ile açmak ve developer hesabı almak için rehbere tıklayınız.

Hazır proje dosyasını indirmek için tıklayınız

VR projemizin düzgün çalışması için aşağıdaki paketler "packace manager" üzerinden kurulmalı.

"Scenes" klasöründeki sahnenin adını "VR Room" yaptık ve açtık.

Hiyerarşi penceresinden XR Origin (VR) GameObject'ini seçtik. XR Origin (VR) > Kamera Kaydırma > Ana Kamera'yı seçin ve Tracked Pose Driver bileşenini inceledik. "Tracked Pose Driver" bileşeni, bir GameObject'i VR başlığınızın veya kontrol cihazlarınızın gerçek dünyadaki konum ve dönüşüne uyacak şekilde otomatik olarak hareket ettirir.

Kontrolcü GameObject'lerinin izlenebilmesi için bu bileşenlere de ihtiyaç vardır. LeftHand Controller GameObject'ini seçin ve bir Tracked Pose Driver (Input System) bileşeni ekledik. Ayarlar düğmesini seçtik ve ardından LeftTrackedPoseDriver ön ayarını seçtik. Bu, bileşenin çalışması için gerekli olan tüm Input Action References'ları ekledi. Aynısını RightHand Controller için de yaptık.

"Tracked Pose Driver (Input System)" bileşeni "XR Interaction Toolkit" paketinden geldi.

Hiyerarşi penceresinde, "Input Action Manager" GameObject'ini seçtik ve "Input Action Manager" bileşenini inceledik. "XRI Default Input Actions" varlığını çift tıklayarak Input Actions Editor penceresini açtık.

Bu "XRI Default Input Actions" varlığı, VR başlığınızın ve kontrol cihazlarınızın oyuna nasıl giriş gönderdiğini tanımlar. Soldaki Eylem Haritaları, farklı giriş türlerini (baş izleme veya el hareketi gibi) gruplandırır. Sağdaki Eylemler ise neyin izlendiğini gösterir (başınızın konumu ve dönüşü gibi). Bu ayar, Unity'nin VR'da gerçekleştirdiğiniz eylemlere yanıt vermesini sağlar.

"XRI Default Input Actions" bileşeni "XR Interaction Toolkit" paketinden geldi.

"_Prefabs" klasöründeki oda ve çevre örnekleri ile sahnemizin başlangıcını oluşturduk.

VR başlığınız bağlı değilse — ya da test sırasında başlık kullanmamayı tercih ediyorsanız — XR Interaction Toolkit'in bir parçası olan Cihaz Simülatörü'nü kullanabilirsiniz. Bu araç, sahnenizi fare ve klavyeyi kullanarak doğrudan Unity Editörü'nde test etmenizi sağlar. Bu özellik, başlık takmaya gerek kalmadan hızlı yinelemeler yapmak ve temel işlevleri test etmek için özellikle kullanışlıdır.

Proje penceresinden Samples > XR Interaction Toolkit > [sürüm] > XR Device Simulator > XRDeviceSimulator klasörlerini açın. XR Device Simulator prefabını Hiyerarşi penceresine sürükleyin. Simülatörü test etmek için Oynatma moduna geçin.

Not: Simülatörü etkili bir şekilde kullanmak için, tıklanabilir kaydırma tekerleği olan bir fare kullanılması önerilir.

  • Kamerayı kontrol etmek için: sağ tıklamayı basılı tutun.
  • Sol kontrol cihazını kontrol etmek için: Sol Shift tuşunu basılı tutun veya T tuşuyla geçiş yapın.
  • Sağ kontrol cihazını kontrol etmek için: Boşluk tuşunu basılı tutun veya Y tuşuyla geçiş yapın.
  • Cihazla etrafta gezinmek için: fareyi hareket ettirin.
  • Cihazı döndürmek için: farenin orta tuşunu basılı tutun.
  • Cihazların konumunu ve dönüşünü sıfırlamak için: V tuşuna basın.

Kullanmayacağımız zaman simulatörü devre dışı bırakmayı unutmamalıyız. Deploy edilirse karışıklığa yol açar.

Unityden VR Headsete Test Yayını

Projeyi Unity aracılığıyla cihazınızda çalıştırmak için, geliştirme amaçlı doğru eklentiyi yüklemeniz gerekir. OpenXR, Unity’yi desteklenen VR donanım cihazlarına bağlayan açık kaynaklı bir API’dir. Tek bir standart API aracılığıyla birden fazla cihaza dağıtım yapmanıza olanak tanıdığından, bu eklentiyi kullanmanız önerilir.

Ana menüden Edit > Project Settings’i seçin, ardından en soldaki panelden XR Plug-in Management sekmesini seçin. Windows, Mac, Linux sekmesinde, mevcut Eklenti Sağlayıcıları listesinden OpenXR'yi seçerek bu eklentiyi yükleyin.

OpenXR eklentisini ekledikten sonra, eklenti adının yanında bir uyarı veya hata simgesi görünebilir.Herhangi bir uyarı veya hata yoksa, cihazınızı Quest Link Yazılımı aracılığıyla bağlamak için aşağıdaki adıma geçebilirsiniz. Bir uyarı varsa, uyarı simgesini seçerek "Project Validation" penceresini açın; bu pencere, kullandığınız cihaz için bir etkileşim profili eklemeniz gerektiğini size bildirecektir. Düzenle düğmesini seçerek OpenXR ayarları panelini açın. Windows, Mac, Linux sekmesinde, Oculus Touch Denetleyici Profilinin Etkileşim Profilleri listesinde göründüğünden emin olun, ardından mevcut tüm OpenXR Özellik Gruplarını etkinleştirin.

Valve Index veya HTC Vive gibi farklı bir cihaz kullanıyorsanız, bunun yerine o cihazın etkileşim profilini ekleyin.

XR Eklenti Yönetimi panelinde artık herhangi bir uyarı olmamalıdır. Varsa, bunları seçin ve önerilen adımları izleyerek sorunları giderin. Uyarıları veya hataları gidermede sorun yaşıyorsanız veya sorun giderme konusunda yardıma ihtiyacınız varsa, OpenXR eklentisini yapılandırma hakkındaki bu ayrıntılı belgelere göz atın.

Cihaz Horizon link ile bağlıyken cihazın içinden Unity play moda alınınca vr sahnemizin içine giriyoruz :D

Cihaza Deploy Etmek

Ana menüden Edit > Project Settings'i seçtik, ardından en soldaki panelden XR Plug-in Management sekmesini seçtik.XR Plug-in Management ayarlarından Android sekmesini seçin, ardından mevcut Eklenti Sağlayıcıları listesinden OpenXR'yi seçerek bu eklentiyi yükleyin.

Görünen yeni uyarı veya hata simgesini seçerek OpenXR Proje Doğrulama penceresini açtık. "Tümünü Düzelt" seçeneği varsa, bazı uyarıları gidermek için bu seçeneği seçtik.

Muhtemelen, bir etkileşim profili eklemeniz gerektiğini belirten bir uyarı hala görünecektir. Düzenle düğmesini seçerek OpenXR ayarları panelini açın. "OpenXR" ayarları panelinde, Android sekmesinde, cihazınız için uygun profili eklemek üzere Ekle (+) düğmesini seçin. Quest modelleri için "Oculus Touch Controller Profile"ı seçin, ardından "Meta Quest Support" özellik gruplarını etkinleştirin. Herhangi bir ek hata veya uyarı görünürse, bunları gidermek için hata veya uyarı simgelerini seçin.

Sahnenizdeki XR Cihaz Simülatörü GameObject'inin devre dışı bırakıldığından emin olun. Eğer etkinse, kafa izleme özelliği çalışmayacaktır.

Ana menüden File > Build Profiles'i seçin. "Open Scene List"ı seçin. Sahnenizi eklemek için "Add Open Scenes"i seçin.

Android platformunu seçin.

VR cihazınızın açık ve prize takılı olduğundan emin olun. "Run Device" açılır menüsünün yanındaki "Refresh" seçeneğini seçin, ardından VR cihazınızı seçin. Cihazınız bir cihaz kimliği veya cihaz adı olarak görünebilir.

"Build and Run"ı tıklayın.

Sorun giderme ipuçları:

  • Uygulama çalışıyor ancak görüş alanının tamamını kaplamıyorsa, sorun büyük olasılıkla eklentilerle ilgilidir.
  • Uygulama çalışıyor ancak tüm sahne başınızın hareketine göre kayıyorsa, bunun nedeni büyük olasılıkla XR Cihaz Simülatörü GameObject'inin etkin olması veya Giriş Eylem Yöneticisi'nin doğru şekilde yapılandırılmamış olmasıdır.

Minimum API Level 29 olmalı. Yoksa Meta Quest (1) e deploy edemez.

Meta Quest (1) eski bir cihaz olduğundan Build Settings'de aşağıdaki ayaralar gerekti.

  • XR Plug-in Management te OpenXR yerine Oculus
  • Player > Other Settingste Vulcan yerine OpenGLE3. (vulcanı tamamen kaldır)
  • Multithreaded Rendering kapalı

Bu örnekte VR sahnemizde ışınlanma yapmayı öğreneceğiz. Hocaya göre ışınlanma kumanda ile kontrolden daha az "VR rahatsızlığı" yapıyor.

Snap Turn (ani dönüş) Ekle

Kontrolcüden gelen işaretle karakterin belirli bir derecede açıyı dönmesini sağladık.

"XR Origin (VR)" GameObject'inin alt öğesi olarak yeni bir boş GameObject ekledik ve buna “Locomotion” adını verdik.

Locomotion GameObject'e bir Locomotion Mediator bileşeni ekledik; bir XR Body Transformer bileşeni otomatik olarak eklendi.

XR Body Transformer bileşeninde, XR Origin (VR) GameObject'e otomatik olarak bir Character Controller bileşeni eklemek için "Add Character Controller" düğmesini seçtik.

Locomotion GameObject'inin alt öğesi olarak yeni bir boş GameObject oluşturduk ve buna “Snap Turn” adını verdik.

Snap Turn GameObject'e bir Snap Turn Provider bileşeni ekledik. İlgili giriş eylemini seçerek, "Left Hand Turn Input" ve "Right Hand Turn Input" özelliklerine uygun "Giriş Eylemi" varlığını atayın: Left hand: XRI Left Locomotion/Snap Turn (Input Action Reference). Right Hand: XRI Right Locomotion/Snap Turn (Input Action Reference).

Locomotion GameObject'ini Mediator özellik kutusuna sürükleyip bıraktık.

Hızlı dönüş deneyimini için ince ayarlar:

    Beğendiğiniz bir ayar bulana kadar "Dönüş Miktarı" ve "Yankılanma Süresi" özellikleriyle denemeler yapın.
  • Dönüş Miktarı özelliği, bir snap dönüş tetiklendiğinde kullanıcının her seferinde ne kadar (derece cinsinden) döndüğünü tanımlar.
  • Yankılanma Süresi özelliği, hızlı ve tekrarlanan dönüşleri önlemek ve yumuşak geçişler sağlamak için izin verilen snap dönüşler arasında minimum gecikmeyi ayarlar.
Kullanıcının joystick'i aşağı bastığında 180 derece dönmesini sağlamak için "Enable Turn Around" özelliğini etkinleştirin.

Önemli Not: mevcut hiyerarşi locomotion sonrası sorun çıkardığı için yeniden düzenlendi.

      • RightSphere

Sürekli Dönüş Ekle

"Sürekli Dönüş" eylemi, VR'da kullanıcının görüş açısını yumuşak bir şekilde döndürmenizi sağlayarak, ani dönüşler yerine akıcı bir dönüş deneyimi sunar.

Uyarı: Bu tür hareketler, VR'a yeni başlayanlar için kafa karıştırıcı olabilir; bu nedenle "Ani Dönüş" genellikle daha güvenli bir seçenektir.

Locomotion GameObject'inin alt öğesi olarak boş bir GameObject oluşturduk ve “Continuous Turn” adını verdik.

"Continuous Turn" GameObject'ine "Continuous Turn Provider" bileşenini ekledik.

  • Left Hand: XRI Left Locomotion/Turn
  • Right Hand: XRI Right Locomotion/Turn
  • Locomotion GameObject'ini Mediator özellik kutusuna sürükleyip bırak

"Snap Turn" ve "Continuous Turn" özelliklerinin aynı anda etkin olmaması tavsiye edilir; bu nedenle, bundan sonra "Left Hand Controller" GameObject'inin sürekli dönüşü, "Right Hand Controller" GameObject'inin ise ani dönüş işlevlerini kontrol edecek şekilde ayarlayacağız.

"Snap Turn" ve "Continuous Turn" hareket modlarını birleştirmek istiyorsanız, bir elin "Snap Turn" hareketini, diğer elin ise "Continuous Turn" hareketini gerçekleştirecek şekilde yapılandırabilirsiniz. Bunu, belirli eller için "Input Actions" öğelerini kaldırarak yapabilirsiniz.

  • "Snap Turn" GameObject'inin "Snap Turn Provider" bileşeninde, "Left Hand Turn Input" özelliğini "None" olarak ayarlayın.
  • "Continuous Turn" GameObject'inin "Continuous Turn" bileşeninde, "Right Hand Turn Input" özelliğini "None" olarak ayarlayın.

Teleport Alanı Ekle

Artık dönme işlevini kullanabildiğinize göre, belirlenen bir alan içindeki farklı noktalara anında taşınmayı sağlayan işlevi de ekleyeceğiz.

Dönme veya serbest hareket etmenin aksine, anında taşınma işlevi kullanıcıyı seçilen bir noktaya anında götürür. Bu, özellikle hareket hassasiyeti olan kullanıcılar için VR ortamında dolaşmanın genellikle daha rahat bir yolu olabilir.

Locomotion GameObject’ini seçtik, yeni bir boş alt GameObject ekledik ve adına “Teleport” adını verdik.Teleport GameObject’ine bir "Teleportation Provider" bileşeni ekledik. Locomotion GameObject’ini Mediator özellik kutusuna sürükleyip bıraktık.

Rug GameObject'ini seçtik ve bir Teleportation Area bileşeni ekledik. Teleport GameObject'ini Teleportation Provider özelliğine sürükleyip bıraktık.

Artık halının herhangi bir noktasına geldiğinizde, çizgi göstergesi beyaz renge döner ve kontrol cihazındaki tutma düğmesini kullanarak o noktaya anında gidebiliyoruz. Tutma düğmesi, kontrol cihazının iç kısmında en altta bulunan düğmedir ve genellikle orta parmakla basılır.

Teleport Noktaları Ekle

Bazen, kullanıcının belirli bir noktaya ışınlanmasını ve belirli bir yöne bakmasını istersiniz. Bu, Işınlanma Noktaları ile gerçekleştirilebilir.

_Course Library > _Prefabs > Rugs klasörlerini açın, ardından odanın önemli noktalarına daha küçük Mat GameObject'leri ekledik. Bu GameObject'leri, yerel Z ekseni (mavi) okları, kullanıcının oraya ışınlandığında durmasını istediğiniz yöne bakacak şekilde döndürdük.

Mat prefab'ına yeni bir "Teleportation Anchor" bileşeni ekleyin. Not: Teleportation Provider özelliğini atamanız aslında gerekli değildir; uygulama çalıştırıldığında bu özellik otomatik olarak atanır. Teleportation Anchor bileşeninde, "Match Orientation" özelliğini "Target Up And Forward" olarak ayarlayın.

Artık odanın dört bir yanındaki matlara ışınlanabilmeli ve vardığınızda matın yönüne göre kendinizi yeniden konumlandırabilmelisiniz.

Test ederken XR Plug-in Management: OpenXR olmazsa hata veriyor. Deployda yine Oculus deneyeceğim.

_Course Library > _Prefabs > Objects > Sports içinden bir "Ball" seçip alana ekledik.

"Ball" GameObject'ine bir "XR Grab Interactable" bileşeni ekledik. XR Grab Interactable bileşeni, GameObject'lerin VR ortamında kaldırılıp hareket ettirilmesini sağlar.

Not: Bu işlem, Ball GameObject'ine de otomatik olarak bir Rigidbody bileşeni ekleyecektir. Rigidbody bileşeni, GameObject'lerin yerçekimi ve çarpışmalar gibi fiziksel etkenlerden etkilenmesini sağlar.

VR'da uzaktaki GameObject'leri kendinize doğru çekerek bir "kuvvetle çekme" efekti simüle etme seçeneğiniz vardır. Right Hand Controller > Right Ray Interactor GameObject'ini seçin. "XR Ray Interactor" bileşeninde, "Force Grab" seçeneğini etkinleştirin. Aynı işlemi Sdiğer taraf ele de yapın. Artık VR'da uzaktaki GameObject'leri kendinize doğru çekebilir ve ışınınızı hedefleyip Grip düğmesine bastığınızda "kuvvet çekme" efektini simüle edebilirsiniz.

Tutulurken Nesne Elleri Gizle ve Tutulan Nesnenin Hareketini Devre Dışı Bırak

Şu anda sahnenizdeki tutma işlevinde iki temel sorun var: Birincisi, el modeli tuttuğunuz GameObject ile üst üste geliyor ve bu da sahneyle etkileşimi zorlaştırıyor; ikincisi ise, tutma işlevi etkinleştirildiğinde ve analog çubuğu hareket ettirdiğinizde, tutulan GameObject elinizde istem dışı bir şekilde dönüyor. Bunu düzelteceğiz

Hiyerarşi penceresinde, Left Ray Interactor GameObject'ini seçtik. XR Ray Interactor bileşeninde, Manipulate Attach Transform özelliğini devre dışı bıraktık. Bu nesnenin tutulurken kendi kendine hareket etmesini engeller.

Nesne tutulduğunda eli yok etmek için: XR Ray Interactor bileşeninde, açılır menüyü (üçgen simgesi) kullanarak Interactor Events bölümünü genişlettik. Select Entered Event özelliğinde, Add (+) düğmesini seçtik. Hierarchy penceresinden Hand_Left prefab'ını kutuya sürükledik ve açılır menüyü açtık ve GameObject > SetActive(Bool) seçeneğini seçerek, nesneyi kavradığınızda elin görünmemesini sağladık.

Nesneyi bırakınca eli ortaya çıkarmak için: "Select Exited Event" özelliğinde, "Add (+)" düğmesini seçtik. "Hierarchy" penceresinden "Hand_Left" prefabını kutuya sürükledik ve açılır menüyü açın ve "GameObject > SetActive(Bool)" seçeneğini seçtik; elin tekrar görünmesi için onay kutusunun işaretli olduğundan emin olun.

Diğer elde işlemleri tekrarladık.

Atış Deneyimini Daha Da İyileştirmek

Topu zıplayabilir hale getirmek: Ball GameObject’in Sphere Collider bileşeninde Material özelliğine sunulan Fizik Malzemelerinden birini seçtik.

Düşen bir GameObject'in zeminden geçmesini önlemek: Ball GameObject'in Rigidbody bileşeninde, Collision Detection özelliğini Continuous Dynamic olarak ayarladık. Dikkat performans maliyeti var.

Çarpışma Algılama özelliği, oyun sırasında çarpışmaların nasıl hesaplanıp çözüleceğini kontrol eder ve GameObject'lerin çarpışmaları ne kadar doğru algılayıp bunlara tepki vereceğini etkiler. Aşağıda farklı seçeneklerin açıklaması yer almaktadır:

  • Discrete: Hızlı ve basittir, ancak hızlı hareket eden GameObject'lerle olan çarpışmaları gözden kaçırabilir.
  • Continuous: Hızlı hareket eden GameObject'lerin diğerlerinin içinden geçmesini engeller.
  • Continuous Dynamic: Sürekli seçeneğine benzer, ancak hızlı hareket eden GameObject'leri birbirleriyle de karşılaştırır.

Topun Rigidbody bileşeninin fizik kurallarının elinizdeyken de çalışmasına izin vermek: Ball GameObject’inin XRI Grab Interactable bileşeninde, Movement Type özelliğinin Kinematic olarak ayarlandığından emin olun." Movement Type" özelliği, bir GameObject’in VR’da yakalandığında nasıl hareket edeceğini belirler. Aşağıda farklı seçeneklerin açıklaması yer almaktadır:

  • Kinematic: GameObject, istikrarlı ve öngörülebilir bir tutuş için fizik kuvvetlerini göz ardı ederek, etkileşimcinin konumuna doğrudan uyacak şekilde hareket ettirilir.
  • Velocity Tracking: GameObject'in Rigidbody bileşeni, hesaplanan kuvvetleri kullanarak onu etkileşimcinin konumuna doğru hareket ettirir ve fiziksel olarak daha doğru bir hareket oluşturur.
  • Instantaneous: GameObject, hareketin ne kadar hızlı veya yavaş olduğuna bakılmaksızın, etkileşimcinin konumuna anında yerleşir.
Bu adımda, hassas kontrol ve istikrarlı kavrama performansı için ayarı "Kinematik" olarak belirleyin.

GameObject'in hareketini yumuşatmak: Ball GameObject'in XRI Grab Interactable bileşeninde, Smooth Position ve Smooth Rotation özelliklerini etkinleştirdik.

Tutma Kolu Olan Bir GameObject Eklemek

Sahneye bir "Racket" prefabı ekledik.

Gerçekçi zıplama sesleri ekleyin [Orta] [Programlama gerektirir]

İlk olarak, topun yere çarpma sesi için bir ses dosyası seçtik. Topa bir Audio Source bileşeni ekledik. Play On Awake seçeneğini kapattık.

BallBounceSound.cs oluşturduk. 

using UnityEngine;

[RequireComponent(typeof(AudioSource))] // Bu scriptin olduğu objede AudioSource yoksa otomatik ekler
[RequireComponent(typeof(Rigidbody))] // Rigidbody yoksa otomatik ekler (çarpışma ve hız için gerekli)
public class BallBounceSound : MonoBehaviour // Script sınıfını tanımlar
{
    [Header("Audio Settings")] // Inspector’da başlık oluşturur

    public AudioClip bounceClip; // Zıplama sesi (Inspector’dan atanır)

    public float minVolume = 0.2f; // Minimum ses seviyesi
    public float maxVolume = 1.0f; // Maksimum ses seviyesi

    public float minSpeed = 0f; // Minimum hız (sesin başlayacağı seviye)
    public float maxSpeed = 10f; // Maksimum hız (sesin tam olacağı seviye)

    private AudioSource audioSource; // AudioSource referansı
    private Rigidbody rb; // Rigidbody referansı

    void Start() // Oyun başladığında çalışır
    {
        audioSource = GetComponent(); // AudioSource bileşenini alır
        rb = GetComponent(); // Rigidbody bileşenini alır
    }

    void OnCollisionEnter(Collision collision) // Obje başka bir şeye çarptığında çalışır
    {
        float speed = rb.linearVelocity.magnitude; // Rigidbody'nin güncel hız vektörünün büyüklüğünü alır.

        float normalizedSpeed = Mathf.InverseLerp(minSpeed, maxSpeed, speed); // Hızı 0-1 arasına çevirir

        float volume = Mathf.Lerp(minVolume, maxVolume, normalizedSpeed); // Hıza göre ses seviyesini hesaplar

        if (bounceClip != null) // Ses atanmış mı kontrol eder
        {
            audioSource.PlayOneShot(bounceClip, volume); // Çarpma sesini çalar
        }
    }
}
Bunu topa ekledik.

Play Quick Sound.cs bileşeninin içeriği 

using UnityEngine; // Unity engine temel kütüphanesi (GameObject, AudioSource vb. için gerekli)

/// <summary>
/// Play a simple sounds using Play one shot with volume, and pitch
/// Basit bir sesi volume ve pitch kontrolüyle PlayOneShot kullanarak çalar
/// </summary>

[RequireComponent(typeof(AudioSource))] 
// Bu scriptin bulunduğu objede AudioSource yoksa otomatik eklenmesini sağlar

public class PlayQuickSound : MonoBehaviour 
// MonoBehaviour: Unity component scripti olarak çalışmasını sağlar
{
    [Tooltip("The sound that is played")]
    // Inspector’da açıklama gösterir
    public AudioClip sound = null; 
    // Çalınacak ses dosyası (Inspector’dan atanır)

    [Tooltip("The volume of the sound")]
    public float volume = 1.0f; 
    // Sesin yüksekliği (0-1 arası genelde)

    [Tooltip("The range of pitch the sound is played at (-pitch, pitch)")]
    // Inspector açıklaması
    [Range(0, 1)] public float randomPitchVariance = 0.0f; 
    // Pitch için rastgele sapma aralığı (0 = sabit, 1 = çok değişken)

    private AudioSource audioSource = null; 
    // AudioSource bileşeni referansı (ses çalma işlemi için)

    private float defaultPitch = 1.0f; 
    // Varsayılan pitch değeri (normal hız/ses tonu)

    private void Awake() 
    // Oyun başlamadan hemen önce çalışır
    {
        audioSource = GetComponent<AudioSource>(); 
        // Bu objedeki AudioSource bileşenini alır ve değişkene atar
    }

    public void Play() 
    // Dışarıdan çağrılarak sesi çalan fonksiyon
    {
        float randomVariance = Random.Range(-randomPitchVariance, randomPitchVariance); 
        // -variance ile +variance arasında rastgele bir pitch sapması üretir

        randomVariance += defaultPitch; 
        // Rastgele değeri normal pitch seviyesine ekler

        audioSource.pitch = randomVariance; 
        // AudioSource’un pitch değerini geçici olarak değiştirir

        audioSource.PlayOneShot(sound, volume); 
        // Sesi volume değeriyle birlikte tek seferlik çalar

        audioSource.pitch = defaultPitch; 
        // Pitch’i tekrar varsayılan değere döndürür (başka sesleri etkilememesi için)
    }

    private void OnValidate() 
    // Inspector’da değer değişince editör tarafında çalışır
    {
        AudioSource audioSource = GetComponent<AudioSource>(); 
        // AudioSource bileşenini tekrar alır (editör güvenliği için)

        audioSource.playOnAwake = false; 
        // Oyun başlar başlamaz otomatik ses çalmasını engeller
    }
}

ChangeMaterial.cs 

using UnityEngine; // Unity temel kütüphanesi (MeshRenderer, Material vb. için gerekli)

/// <summary>
/// This script makes it easier to toggle between a new material, and the objects original material.
/// Bu script, bir objenin orijinal materyali ile yeni materyal arasında geçiş yapmayı sağlar.
/// </summary>

public class ChangeMaterial : MonoBehaviour 
// MonoBehaviour: Unity component olarak çalışmasını sağlar
{
    [Tooltip("The material that's switched to.")]
    // Inspector’da açıklama gösterir (hangi materyale geçileceği)
    public Material otherMaterial = null; 
    // Değiştirilecek alternatif materyal

    private bool usingOther = false; 
    // Şu anda alternatif materyal kullanılıyor mu? (true/false)

    private MeshRenderer meshRenderer = null; 
    // Objeyi görsel olarak çizen MeshRenderer bileşeni

    private Material originalMaterial = null; 
    // Objeye başlangıçta atanmış orijinal materyal

    private void Awake() 
    // Oyun başlamadan hemen önce çalışır
    {
        meshRenderer = GetComponent<MeshRenderer>(); 
        // Objedeki MeshRenderer bileşenini alır

        originalMaterial = meshRenderer.material; 
        // Başlangıç materyalini kaydeder (geri dönmek için)
    }

    public void SetOtherMaterial() 
    // Objeyi alternatif materyale geçirir
    {
        usingOther = true; 
        // Durumu “alternatif kullanılıyor” olarak işaretler

        meshRenderer.material = otherMaterial; 
        // Objeye yeni materyali uygular
    }

    public void SetOriginalMaterial() 
    // Objeyi orijinal materyaline geri döndürür
    {
        usingOther = false; 
        // Durumu “orijinal kullanılıyor” olarak işaretler

        meshRenderer.material = originalMaterial; 
        // Orijinal materyali tekrar uygular
    }

    public void ToggleMaterial() 
    // İki materyal arasında geçiş yapar
    {
        usingOther = !usingOther; 
        // true ise false, false ise true yapar (toggle mantığı)

        if(usingOther) 
        // Eğer alternatif materyal aktifse
        {
            meshRenderer.material = otherMaterial; 
            // Alternatif materyali uygula
        }
        else 
        // Değilse
        {
            meshRenderer.material = originalMaterial; 
            // Orijinal materyali geri yükle
        }
    }
}

Tetikleyiciye basıldığında malzeme rengini kırmızıya değiştirmek: Remote ana GameObject'inde, "XR Grab Interactable" bileşeninin alt kısmında "Interactable Events" özelliğini içinde diğer fonksiyonu eklediğimiz şekilde "Activated" olayına "Change Material > SetOtherMaterial ()" fonksiyonunu, "Deactivated" olayına da "Change Material > SetOriginalMaterial ()" olayını ekledik.

Bu, bir GameObject'in bir listeden veya tek bir klipten videoları oynatmasını sağlayan, isteğe bağlı olarak yükleme sırasında başlatma özelliğine sahip, görüntüleme için bir video malzemesi ve oynatma, duraklatma, durdurma ve gezinme kontrolleri kullanan, eğitim sağlanan özel bir komut dosyasıdır. Videonun otomatik olarak oynatılması için Play At Start özelliğini etkinleştirdik.

PlayVideo.cs 

using System.Collections.Generic; // List yapısını kullanabilmek için gerekli
using UnityEngine; // Unity temel kütüphanesi
using UnityEngine.Video; // VideoPlayer bileşeni için gerekli namespace

/// <summary>
/// Play a single video or play from a list of videos 
/// Tek bir video oynatır veya bir liste içinden video seçerek oynatır
/// </summary>

[RequireComponent(typeof(VideoPlayer))] 
// Bu scriptin olduğu objede VideoPlayer yoksa otomatik ekler

public class PlayVideo : MonoBehaviour 
// Unity component scripti
{
    [Tooltip("Whether video should play on load")]
    public bool playAtStart = false; 
    // Oyun başlar başlamaz video oynasın mı?

    [Tooltip("Material used for playing the video (Uses URP/Unlit by default)")]
    public Material videoMaterial = null; 
    // Videonun gösterileceği materyal (ekranda görünen yüzey)

    [Tooltip("List of video clips to pull from")]
    public List<VideoClip> videoClips = new List<VideoClip>(); 
    // Oynatılabilecek video listesi

    private VideoPlayer videoPlayer = null; 
    // Video oynatıcı referansı

    private MeshRenderer meshRenderer = null; 
    // Objeyi render eden bileşen

    private readonly string shaderUsed = "Universal Render Pipeline/Unlit"; 
    // Kullanılacak shader (video için genelde Unlit gerekir)

    private Material offMaterial = null; 
    // Video kapalıyken kullanılacak materyal

    private int index = 0; 
    // Şu an oynatılan videonun index’i

    private void Awake() 
    // Oyun başlamadan önce çalışır
    {
        meshRenderer = GetComponent<MeshRenderer>(); 
        // MeshRenderer bileşenini al

        videoPlayer = GetComponent<VideoPlayer>(); 
        // VideoPlayer bileşenini al

        if (videoClips.Count > 0) 
            videoPlayer.clip = videoClips[0]; 
        // Eğer listede video varsa ilkini ata

        offMaterial = meshRenderer.material; 
        // Başlangıç materyalini kaydet (video kapalıyken geri dönmek için)
    }

    private void OnEnable() 
    // Script aktif olduğunda çalışır
    {
        videoPlayer.prepareCompleted += ApplyVideoMaterial; 
        // Video hazır olduğunda ApplyVideoMaterial fonksiyonunu çağır
    }

    private void OnDisable() 
    // Script devre dışı kalınca çalışır
    {
        videoPlayer.prepareCompleted -= ApplyVideoMaterial; 
        // Event aboneliğini kaldır (memory leak önlemek için)
    }

    private void Start() 
    // Oyun başladığında çalışır
    {
        if (playAtStart) 
        {
            Play(); // Eğer işaretliyse videoyu başlat
        }
        else
        {
            Stop(); // Değilse durdurulmuş başlasın
        }
    }

    public void NextClip() 
    // Bir sonraki videoya geçer
    {
        index = ++index % videoClips.Count; 
        // Index artırılır ve liste sonunu aşarsa başa döner (mod işlemi)

        Play(); 
        // Yeni videoyu oynat
    }

    public void PreviousClip() 
    // Bir önceki videoya geçer
    {
        index = --index % videoClips.Count; 
        // Index azaltılır (negatifte bug olabilir dikkat!)

        Play(); 
        // Videoyu oynat
    }

    public void RandomClip() 
    // Rastgele video seçer
    {
        if (videoClips.Count > 0)
        {
            index = Random.Range(0, videoClips.Count); 
            // Rastgele index seç

            Play(); 
            // Oynat
        }
    }

    public void PlayAtIndex(int value) 
    // Belirli index’teki videoyu oynatır
    {
        if (videoClips.Count > 0)
        {
            index = Mathf.Clamp(value, 0, videoClips.Count); 
            // Index’i sınırlar (⚠️ burada aslında Count-1 olmalı)

            Play(); 
        }
    }

    public void Play() 
    // Video oynatma fonksiyonu
    {
        ApplyVideoMaterial(videoPlayer); 
        // Video materyalini uygula

        videoPlayer.Play(); 
        // Videoyu başlat
    }

    public void Stop() 
    // Video durdurma fonksiyonu
    {
        meshRenderer.material = offMaterial; 
        // Eski materyale geri dön

        videoPlayer.Stop(); 
        // Videoyu durdur
    }

    public void TogglePlayStop() 
    // Play / Stop arasında geçiş yapar
    {
        bool isPlaying = !videoPlayer.isPlaying; 
        // Şu an oynuyorsa durdur, oynamıyorsa başlat

        SetPlay(isPlaying); 
    }

    public void TogglePlayPause() 
    // Play / Pause arasında geçiş yapar
    {
        meshRenderer.material = videoMaterial; 
        // Video materyalini aktif et

        if (videoPlayer.isPlaying)
            videoPlayer.Pause(); // Oynuyorsa pause
        else
            videoPlayer.Play(); // Değilse devam et
    }

    public void SetPlay(bool value) 
    // Dışarıdan kontrol (true=play, false=stop)
    {
        if (value)
        {
            Play();
        }
        else
        {
            Stop();
        }
    }

    private void ApplyVideoMaterial(VideoPlayer source) 
    // Video hazır olduğunda çağrılır
    {
        meshRenderer.material = videoMaterial; 
        // Video materyalini uygula

        videoMaterial.color = Color.white; 
        // Siyahsa video görünmez, beyaz yaparak görünmesini sağla
    }

    private void OnValidate() 
    // Inspector’da değişiklik olunca çalışır
    {
        if (!videoMaterial) 
        {
            videoMaterial = new Material(Shader.Find(shaderUsed)); 
            // Eğer materyal yoksa otomatik oluştur
        }

        if (TryGetComponent(out VideoPlayer videoPlayer))
            videoPlayer.targetMaterialProperty = "_BaseMap"; 
        // URP shader’da videonun hangi property’e yazılacağını belirler
    }
}

Çekmeceleri Hafifçe Açıp Kapatmak

using UnityEngine;
using System.Collections;

public class ChangeLocalPosition : MonoBehaviour
{
    // Başlangıç (kapalı) pozisyonu
    private Vector3 _initialLocalPosition;

    // Çekmecenin açık olacağı pozisyon (Inspector’dan verilecek)
    [SerializeField] private Vector3 _newLocalPosition;

    // Hareket hızı (büyüdükçe daha hızlı açılır/kapanır)
    [SerializeField] private float _speed = 2f;

    // Şu an açık mı kapalı mı bilgisini tutar
    private bool _hasBeenChanged = false;

    // Aynı anda birden fazla coroutine çalışmasın diye referans tutuyoruz
    private Coroutine _moveCoroutine;

    void Start()
    {
        // Oyunun başındaki local pozisyonu kaydet
        _initialLocalPosition = transform.localPosition;
    }

    // XR event’ine bağlayacağın fonksiyon (tıklayınca çağrılır)
    public void ChangePosition()
    {
        // Eğer obje hâlâ hareket ediyorsa, önce durdur (çakışmayı önler)
        if (_moveCoroutine != null)
            StopCoroutine(_moveCoroutine);

        // Hedef pozisyonu belirle (açık mı kapalı mı)
        Vector3 target = _hasBeenChanged ? _initialLocalPosition : _newLocalPosition;

        // Yumuşak hareket coroutine’ini başlat
        _moveCoroutine = StartCoroutine(MoveToPosition(target));

        // Durumu tersine çevir (toggle mantığı)
        _hasBeenChanged = !_hasBeenChanged;
    }

    // Objeyi zaman içinde hedef pozisyona götüren coroutine
    private IEnumerator MoveToPosition(Vector3 target)
    {
        Vector3 startPos = transform.localPosition;
        float time = 0f;

        // time 0 → 1 arası ilerler
        while (time < 1f)
        {
            // Frame’e göre zamanı arttır (frame-rate bağımsız hareket)
            time += Time.deltaTime * _speed;

            // Smoothstep (ease in - ease out)
            // Başta yavaş → ortada hızlı → sonda tekrar yavaş
            float t = time * time * (3f - 2f * time);

            // Pozisyonu yumuşak şekilde güncelle
            transform.localPosition = Vector3.Lerp(startPos, target, t);

            yield return null; // bir sonraki frame’i bekle
        }

        // En sonda tam hedefe oturt (floating point hatalarını önler)
        transform.localPosition = target;
    }
}

Sahne Yüklendiğinde Yavaşça Görüntüye Geçmek

Tuvalin ve tüm öğelerinin solmasını sağlamak: "Fade_Canvas" GameObject’ine bir "Canvas Group" bileşeni ve bir "Fade Canvas" (eğitim tarafından) bileşeni ekledik. 

using System.Collections;
using UnityEngine;

/// <summary>
/// Fades a canvas over time using a coroutine and a canvas group
/// </summary>
[RequireComponent(typeof(CanvasGroup))]
public class FadeCanvas : MonoBehaviour
{
    [Tooltip("The speed at which the canvas fades")]
    public float defaultDuration = 1.0f;

    public Coroutine CurrentRoutine { private set; get; } = null;

    private CanvasGroup canvasGroup = null;
    private float alpha = 0.0f;

    private float quickFadeDuration = 0.25f;

    private void Awake()
    {
        canvasGroup = GetComponent<CanvasGroup>();
    }

    public void StartFadeIn()
    {
        StopAllCoroutines();
        CurrentRoutine = StartCoroutine(FadeIn(defaultDuration));
    }

    public void StartFadeOut()
    {
        StopAllCoroutines();
        CurrentRoutine = StartCoroutine(FadeOut(defaultDuration));
    }

    public void QuickFadeIn()
    {
        StopAllCoroutines();
        CurrentRoutine = StartCoroutine(FadeIn(quickFadeDuration));
    }

    public void QuickFadeOut()
    {
        StopAllCoroutines();
        CurrentRoutine = StartCoroutine(FadeOut(quickFadeDuration));
    }

    private IEnumerator FadeIn(float duration)
    {
        float elapsedTime = 0.0f;

        while (alpha <= 1.0f)
        {
            SetAlpha(elapsedTime / duration);
            elapsedTime += Time.deltaTime;
            yield return null;
        }
    }

    private IEnumerator FadeOut(float duration)
    {
        float elapsedTime = 0.0f;

        while (alpha >= 0.0f)
        {
            SetAlpha(1 - (elapsedTime / duration));
            elapsedTime += Time.deltaTime;
            yield return null;
        }
    }

    private void SetAlpha(float value)
    {
        alpha = value;
        canvasGroup.alpha = alpha;
    }
}

using UnityEngine;
using UnityEngine.XR.Interaction.Toolkit.Interactors;

public class ToggleNearFarAttach : MonoBehaviour
{
    [Header("Near-Far Interactor")]
    // Unity 6'nın gerçek NearFarInteractor component'i
    public NearFarInteractor nearFarInteractor;

    /// <summary>
    /// Toggle tarafından çağrılır
    /// true  = Distance Grab (Far) açık
    /// false = Distance Grab kapalı
    /// </summary>
    public void SetFarAttachMode(bool isOn)
    {
        // Referans kontrolü
        if (nearFarInteractor == null)
        {
            Debug.LogWarning("NearFarInteractor atanmadı!");
            return;
        }

        // 🔥 UZAKTAN GRAB'I AÇ/KAPAT
        nearFarInteractor.enableFarCasting = isOn;

        // (Opsiyonel) Yakın grab hep açık kalsın istiyorsan dokunma
        // nearFarInteractor.enableNearCasting = true;

        Debug.Log("Distance Grab (Far): " + (isOn ? "AÇIK" : "KAPALI"));
    }
}

Modları değiştirmek için Distance Grab anahtarını bağlamak: Toggle bileşeninde, On Value Changed özelliğinde, yeni bir eylem eklemek için Add (+) düğmesini seçtik. "NearFarModeToggle" komut dosyasını barındıran GameObject'i Object kutusuna atadık. No Function açılır menüsünü açtık ve NearFarModeToggle > SetFarAttachMode(bool) seçeneğini seçtik. Optimizasyon

Bu derste, VR için temel performans ölçütlerinin her birini (fps, poligon sayısı ve çizim çağrıları) ve bu ölçütlerin nasıl optimize edileceğini öğreneceğiz. Bu dersin sonunda, uygulamanızın performansı daha da optimize edilmiş olacak.

Mevcut Kare Hızını Kontrol Etmek

Cihazınızın hedef kare hızını (fps) belirlemek: Aşağıdaki bağlantıları referans olarak kullanın ve hedef fps değerinizi not alın.

  • Meta Quest
    • Medya uygulamaları 60 FPS'yi hedefleyebilir.
    • Etkileşimli uygulamalar en az 72 FPS'ye ulaşmalıdır.
  • HTC Vive
    • Vive Focus Plus uygulamaları için hedef kare hızı 75 FPS'dir. Bu, her karenin 1/75 = 13,3 ms içinde işlenmesi gerektiği anlamına gelir.
    • Mobil VR, bağımsız başlıklar masaüstü bilgisayarlar ve dizüstü bilgisayarlar kadar güçlü olmadığından, PC tabanlı VR'ye kıyasla oldukça yüksek performans gerektirir.

Cihazınızda çalışan kare hızını (fps) belirlemek: _Course Library > _Prefabs > Testing klasöründen FPS Overlay UI prefabını Hierarchy pencerenize sürükledik. "Main Camera" GameObject'i, "FPS Overlay UI prefab"ının "Canvas" bileşeninin "Render Camera" özelliğine atadık. Uygulamanızı çalıştırarak fps değerinizi gördük. Not: Uygulamayı Unity Editor üzerinden çalıştırıyorsanız, bu fps için doğru bir tahmin olmayacaktır.

Unity Stats penceresinde fps değerini görüntülemek: Game görünümünün sağ üst köşesindeki Stats sekmesini seçtik ve fps değerini bulduk.

Unity Profiler'ı incelemek: Play düğmesini seçtik. Ana menüden Window > Analysis > Profiler'ı seçtik. Profiler penceresi kayıt yapmıyorsa, Profiler penceresindeki dairesel kayıt düğmesini seçeriz.

Mobil bir başlıkta çalışan gerçek saniye başına kare sayısını test etmek için: Uygulamayı derleyip bilgisayarınıza bağlı olmadan cihazınızda çalıştırın. Artık cihazınız için hedef metrikleri nerede bulacağınızı ve cihazınızda saniye başına kare sayısını nasıl bulacağınızı biliyoruz.

Çizim Çağrılarını Optimize Etmek

Tek bir kareyi görüntülemek için Unity, öğeleri GameObject grupları halinde ekrana çizer. Unity'nin motoru ekrana bir şey çizmesi için her çağrısı, bir çizim çağrısı olarak adlandırılır. Çizim çağrılarını en aza indirirseniz, performansı artırabilirsiniz.

Cihazınızın hedef çizim çağrılarını (batches) belirlemek: Hedef çizim çağrısı ölçütünü öğrenmek için platformunuzun web sitesine bakın.Meta Quest için VR Performans Optimizasyonu Kılavuzuna bakarsanız, örneğin Meta Quest 3 için hedef çizim çağrılarının 500 - 1000 arasında olduğunu göreceksiniz.

Toplu işleme ve çizim çağrılarının kare hızını nasıl etkileyebileceğini görselleştirmek: Ana menüden "Window > Analysis > Frame Debugger"ı seçtik. Etkinleştir'i seçtik. Kare Hata Ayıklayıcı penceresindeki sol/sağ oklarını kullandık ve Oyun görünümünde tek bir karenin adım adım oluşturulmasını izledik.

Statik Toplu İşleme'nin etkinleştirildiğinden emin olmak: Ana menüden "Edit > Project Settings"i seçtik. En soldaki panelden "Player"ı seçtik. Açılır menüyü (üçgen) kullanarak "Other Settings" bölümünü genişletin, ardından "Static Batching"in etkinleştirildiğinden emin olduk.

Hareket etmeyen GameObject'leri Statik olarak işaretleyerek toplu işlemeyi iyileştirmek: Hiyerarşi pencerenizin, tüm statik GameObject'lerin kolayca seçilebileceği şekilde düzenlendiğinden emin olduk. Tüm statik GameObject'leri (lambalar ve avizeler gibi aydınlatma GameObject'leri dahil) seçtik. Inspector penceresinin üst kısmında Static özelliğini etkinleştirdik. İstenildiğinde "Yes, change children" seçeneğini seçtik. Play düğmesini seçtiğinizde bunun "Batches" üzerinde yarattığı etkiye dikkat edin.

Batches sayınız hala çok yüksekse (175'in üzerinde): Mirror GameObject'i sahneden kaldırmayı düşünün.

Ortak malzemelere sahip GameObject'leri gruplandırarak, artık çizim çağrılarının sayısını azaltmış olmalısınız.

Poligon Sayısını Optimize Etmek

En basit performans ölçütü, poligon sayısıdır. Poligon sayısı genellikle üçgen sayısı (Tris) veya köşe sayısı (Verts) olarak ölçülür.

Cihazınızın hedef poligon sayısını (üçgen) belirlemek: Hedef üçgen sayısını öğrenmek için platformunuzun web sitesine bakın.

Sahnenizdeki üçgen sayısını bulmak: Game Stats penceresini açın ve “tris” (üçgen) değerini bulduk.

Üçgenlerinizi daha net bir şekilde görüntülemek: "Scene" görünümünden, "Shaded" çizim modundan "Wireframe" çizim moduna geçtik.

Tek bir GameObject için üçgen sayısını belirlemek: Bir GameObject seçtik. Mesh Filter bileşeninde, Mesh özelliğini seçtik. "Project" penceresinde o Mesh'i seçerek "Inspector" penceresinde üçgen sayısını görüntüledik. Not: 1.000 tris'in altındaki her şey düşük poligonlu olarak kabul edilir.

Karedeki GameObject'lere bağlı olarak üçgen sayınızın nasıl değiştiğine dikkat etmek: XR Origin (VR) GameObject'ini döndürürken istatistik penceresini takip edin.

Önerilen üçgen hedefine ulaşamıyorsanız: Hedefinize ulaşana kadar yüksek poligon sayısına sahip varlıkları kaldırın veya değiştirin. Ayrıca sahneden aynayı kaldırmayı da deneyebilirsiniz. Artık Tris hedefinize ulaşmış olmalısınız ve üçgen bütçenizi nereye harcadığınızı anlamış olmalısınız.

Dokuları Optimize Etmek

Unity'nin yaptığı çizim çağrılarını değerlendirmenin yanı sıra, sahnenizde kullanılan dokuların boyutunu da göz önünde bulundurmak önemlidir.

Doku ayarlarının etkisini daha iyi analiz etmek için sahneye bir tablo ekleyin: _Course Library > _Prefabs > Art klasöründen sahnenizdeki bir duvara bir sanat eseri ekleyin.

Sahnenizdeki GameObject’lerin malzemesine erişmek: Tablonun "Mesh Renderer" bileşeninde, açılır menüyü (üçgen) kullanarak "Material" bölümünü genişlettik. Project penceresinde malzemeyi seçin.

Malzeme için kullanılan doku atlasını bulmak: Açılır menüyü (üçgen) kullanarak malzemenin "Surface Inputs" bölümünü genişlettik, ardından "Base Map" özelliğinin yanındaki küçük resmi seçerek "Project" penceresinde dokuyu bulduk. Bu dokuyu seçerek dokunun "Import Settings" (İçe Aktarma Ayarları) bölümünü görüntüledik.

Doku ayarlarıyla denemeler yapmak: Dokunun "Default" (Varsayılan) sekmesi altında "Max Size" (Maksimum Boyut), "Resize Algorithm" (Yeniden Boyutlandırma Algoritması), "Format" (Biçim) ve "Compression" (Sıkıştırma) özelliklerini ayarladık. "Apply" (Uygula) seçeneğini seçerek her ayarın sahnenizdeki görseller üzerinde yarattığı etkiyi gördük. Farkı gözlemledikten sonra orijinal ayarlara geri döndük.

Uzaktan görülen dokuların çözünürlüğünü otomatik olarak düşürmek için mipmap'leri etkinleştirmek: Proje penceresinde "InteriorColorSwatch" dokusunu bulduk ve seçtik. Denetçi penceresinde, açılır menüyü (üçgen simgesi) kullanarak "Advanced" bölümünü genişlettik ve "Generate Mip Maps" seçeneğini seçtik. Apply'ı seçtik. Bu, daha uzaktaki GameObject'lerde daha düşük kaliteli dokular oluşturup uygulayacaktır.

Düşük açılardan bakıldığında dokuların görselliğini iyileştirmek için "Anisotropic Filtering"i etkinleştirmek: Project penceresinde "WoodFloor_Texture"ı bulduk ve seçtik. Inspector penceresinde, "Aniso Level" kaydırıcısını sürükleyerek artırdık. "Apply"ı seçtik. Bu, düşük açılardan bakıldığında doku görselliğini iyileştirmek için "Anisotropic Filtering"i artıracaktır.

Parçacıkları (particles) ve Son İşlem (post-processing) Adımlarını Optimize Etmek

Parçacığın gölgelendiricisini, dinamik ışıklara tepki vermeyecek şekilde optimize etmek: "Particle_Fire" GameObject’ini seçtik. Inspector penceresinin altındaki "Shader" özelliği açılır menüsünü açtık. Parçacığınızın "Universal Render Pipeline > Particles > Unlit" gölgelendiricisini kullandığından emin olduk.

Son işlemlerle denemeler yapmak: "XR Origin (VR) > Camera Offset > Main Camera" GameObject’inizin "Camera" bileşeninde, açılır menüyü (üçgen) kullanarak "Rendering" bölümünü genişlettik, ardından "Post-processing" özelliğini etkinleştirdik. Bir "Volume" bileşeni ekledik. Yeni bir "Post-Processing" profili oluşturmak için "New" düğmesini seçtik. Ardından "Add Override" düğmesini seçip yeni efektleri etkinleştirerek denemeler yapabiliriz.

Uyarı: Herhangi bir post-processing efekti ekleyecekseniz, renk ayarlamaları (color adjustments) iyi bir seçenektir. Lens distorsiyonları (Lens distortions) ve hareket bulanıklıkları (motion blurs) siber hastalığa neden olur; bu efektleri kullanmaktan kaçının.

  • Shader türleri hakkında bilgi almak için tıklayınız.
  • Post-Processing hakkında bilgi almak için tıklayınız.

Anti-Aliasing (Yumuşatma) Özelliğini Etkinleştirmek

Bazı 3B GameObject'lerin kenarlarının pürüzlü göründüğünü fark etmiş olabilirsiniz. Bu durum VR deneyiminde gerçekçiliği bozabilir. Anti-aliasing özelliğini kullanarak bu pürüzlü kenarları yumuşatabilirsiniz.

Render boru hattı ayarlarına erişmek: Proje penceresinde “UniversalRenderPipelineAsset” öğesini aradık ve seçerek Inspector penceresinde özelliklerini görüntüledik.

Universal Render Pipeline (URP) varlığında anti-aliasing (kenar yumuşatmayı) etkinleştirmek: Açılır menüyü (üçgen) kullanarak "Quality" bölümünü genişlettik, ardından Anti-Aliasing (Kenar Yumuşatma) özelliğini Devre Dışı konumundan 4x olarak değiştirdik.

Ana Kameraya ek anti-aliasing eklemek: "XR Origin (VR) > Camera Offset > Main Camera" GameObject öğesini seçtik ve Camera bileşeninde açılır menüyü (üçgen) kullanarak "Rendering" bölümünü genişlettik. "Anti-Aliasing" özelliğini "Fast Approximate Anti-Aliasing (FXAA)" olarak değiştirdik. Efekti görebilmek için Post-Processing ayarının etkinleştirildiğinden emin olduk.

Not: Bu, fps üzerinde önemli bir etkiye sahip olabilir.

Mirror GameObject'e anti-aliasing uygulamak: Projenizde "Mirror_Texture"ı bulduk. Anti-Aliasing özelliğini "None"dan 4 samples'a değiştirdik. Main Camera GameObject'iniz ve Mirror GameObject'iniz artık eskisinden çok daha pürüzsüz kenarlara sahip olmalıdır.

Aydınlatma Ayarlarınızla Denemeler Yapmak

Render boru hattı ayarlarına erişmek: Proje penceresinde UniversalRenderPipelineAsset dosyasını aradık ve seçtik. UniversalRenderPipelineAsset, grafiklerin Universal Render Pipeline kullanılarak nasıl render edileceğini tanımlayan ve kalite, ışıklandırma, gölgeler ve performans ayarlarını kontrol etmenizi sağlayan bir Unity yapılandırma dosyasıdır.

Render boru hattı ayarlarıyla denemeler yapmak: URP Asset'in Inspector penceresinde, açılır menüyü (üçgen) kullanarak Lighting bölümünü genişlettik, ardından ayarlarla denemeler yaptık.

Karmaşık aydınlatmaya getirdiği sınırlamaları anlamak için Per Object Limit özellik kaydırıcısını mutlaka deneyin. Bu ayar, her bir GameObject'i ayrı ayrı etkileyebilecek ışık sayısını kontrol eder. Per Object Limit özellik kaydırıcısını denemek, Unity'nin aydınlatma karmaşıklığını nasıl sınırladığını görmenize yardımcı olur; GameObject başına daha az ışık performansı artırabilir, ancak karmaşık sahnelerde görsel kaliteyi düşürebilir.

Açılır menüyü (üçgen) kullanarak Shadow bölümünü genişletin, ardından sahnedeki gölge kalitesinden memnun kalana kadar Max Distance özellik değerini azaltın. Bu ayar, performansı artırmak için kameradan gölge oluşturma mesafesini sınırlar. Daha yüksek değerler, hassasiyetin azalması nedeniyle gölge yayılmasına ve kalite sorunlarına neden olabilir.

Sahneniz için yeni Aydınlatma Ayarları oluşturmak: Ana menüden "Window > Rendering > Lighting" seçeneğini seçerek "Lighting" penceresini açtık. Lighting penceresini Inspector penceresinin yanına yerleştirdik. Açılır menüyü (üçgen simgesi) kullanarak "Lighting Settings" bölümünü genişlettik, ardından "New" düğmesini seçerek yeni bir profil oluşturduk.

Sahnenizdeki ortam aydınlatmasıyla denemeler yapmak: "Lighting" penceresinin üst kısmında "Environment" sekmesini seçtik. Ayarlarla denemeler yaparak bunların sahnenize etkisini gördik. Bu ayarlar hakkında daha fazla bilgiyi "Lighting window reference documentation"e tıklayarak bulabilirsiniz.

Basit Bir Işık Haritası (Lightmap) Hazırlamak ve Pişirmek (Bake)

İlk ışık haritası pişirme işleminizi gerçekleştirmenin zamanı geldi. Öncesinde atmanız gereken birkaç adım var.

Tüm ışıklarınızın pişirilmesine izin vermek: Sahnede hareket etmeyecek veya açılıp kapanmayacak her bir ışığı bulduk ve seçtik. Bunu, Hiyerarşi penceresinin arama çubuğunda “t:light” ifadesini arayarak yapabilirsiniz. Her ışığın Light bileşeninde, Mode özelliğini Baked olarak ayarladık.

Sahnenizdeki GameObject'lere ışık pişirilmesine izin vermek: Hierarchy penceresinde, hareket etmeyen, statik tüm GameObject'leri seçtik. Inspector penceresinin üst kısmında, Static özelliğinin etkinleştirildiğinden emin olduk. Not: Aydınlatma bölümünüzdeki GameObject'leri (örneğin, lambalar, aplikler, avizeler vb.) seçmeyi unutmayın.

Fırınlama sürelerini kısaltmak için ışık haritanızdan arka plan (background) ve ön plan (foreground) GameObject'lerini kaldırmak: Her bir büyük arka plan GameObject'ini seçtik. Mesh Renderer bileşeninde, açılır menüyü (üçgen) kullanarak Lightmapping bölümünü genişlettik, ardından "Scale in Lightmap" özelliğini 0 olarak ayarladık.

Işıklarınızı pişirmeyi denemek: "Lighting" penceresine gittik. "Scene" sekmesinin alt kısmında "Generate Lighting" seçeneğini seçtik.

Işık haritasını oluşturma süresini geçici olarak kısaltmak: "Lighting" penceresinde, üst kısımdaki "Scene" düğmesini seçtik ve "Lightmap Resolution" özelliğini 5 ile 10 arasında bir değere ayarladık. Işık haritasının kalitesini etkileyen diğer bazı değerleri (samples, bounces, vb.) azalttık. Bu ayarlar ve pişirme süreleri üzerindeki etkileri hakkında daha fazla bilgiyi, Aydınlatma Ayarları Varlık referans belgelerindeki Işık Haritalama ayarlarında bulabilirsiniz.

Sahne Aydınlatmasını Ayarlamak ve Yeniden İşleme Almak

Işık haritanızı temizlemek ve aydınlatma değişikliklerini gerçek zamanlı olarak görüntülemek: "Lighting" penceresinin alt kısmında, "Generate Lighting" açılır menüsünü açtık. "Clear Baked Data" seçeneğini seçtik.

Mümkün olduğunca çok sayıda ışığın etkisini görüntülemek: "UniversalRenderPipelineAsset" öğesini seçtik. "Additional Lights Per Object Limit" özelliğini geçici olarak maksimuma çıkardık.

Room prefab'iyle birlikte gelen varsayılan ışıkları kaldırmak: Hierarchy penceresinde, açılır menüyü (üçgen) kullanarak "Room_[style]" prefab'ini genişlettik. İki "Point Lights" alt GameObject'ini sildik. Not: Işıkları silmek için Room prefab'ini açmanız gerekir.

Sahnenize gerçek ışık kaynaklarından daha gerçekçi bir aydınlatma eklemek: "_Course Library > _Prefabs > Lighting" klasöründen, sahnenizi aydınlatmak için yeterli sayıda ışık yayan GameObject'iniz olduğundan emin olduk. Bu aydınlatma öğelerine Light alt GameObject'leri eklemek için, Hiyerarşi penceresinde üzerlerine sağ tıklayın ve "Light > Point Light" veya "Spot Light'ı seçin.

Odada daha eşit ve dengeli bir aydınlatma elde etmek: "Directional Light" GameObject’in Light bileşeninde, açılır menüyü (üçgen) kullanarak "Emission" bölümünü genişlettik, ardından "Intensity" ve "Indirect Multiplier" özellik değerlerini artırdık. "Lighting" penceresinde, "Lighting" ayarlarınızı seçtik ve "Indirect Intensity" özellik değerini artırdık. Not: Bu ayarların etkisi hakkında daha fazla bilgiyi, Lighting Settings Asset referans belgelerindeki Lightmapping ayarlarında bulabilirsiniz.

Aydınlatmanın nasıl göründüğünü kontrol etmek: Tekrar "Generate Lighting" seçeneğini seçtik. Vaktiniz varsa, "Lightmap Resolution" ve diğer aydınlatma ayarlarının değerlerini artırarak son haliyle nasıl görüneceğini kontrol edin. Not: Lekeli veya pikselli gölgeler görüyorsanız, "Lighting" penceresinde "Lightmap Compression" özelliğini "None" olarak ayarlayın.

Mixed Lighting Eklemek

GameObject'lerinizin gerçek zamanlı olarak gölge oluşturmasını, ancak aynı zamanda önceden hesaplanmış ışık haritalarının performans avantajlarından da yararlanmasını istiyorsanız, Mixed Lighting özelliğini kullanabilirsiniz.

Önceden işlenmiş ışık haritalarınızın üzerine gerçek zamanlı gölgeler eklemek: "Directional Light" GameObject'inin "Light" bileşeninde, açılır menüyü (üçgen simgesi) kullanarak "General" bölümünü genişlettik. "Mode" özelliğinin açılır menüsünü açtık ve "Mixed"ı seçtik.

Yeni karışık aydınlatmanın etkisini görmek: Lighting penceresinde, "Generate Lighting"i seçerek aydınlatmanızı yeniden pişirdik. Karışık ışığın dinamik GameObject'lerinizin aydınlatması ve gölgeleri üzerinde ne gibi bir etki yarattığına dikkat edin. Artık dinamik GameObject'lerinizde Directional Light GameObject'inizden gelen gerçek zamanlı gölgeler görmelisiniz.

Işık Sensörleri (Light Prob) Eklemek

Sahnedeki tüm önceden hesaplanmış ışıklandırmalardan daha gerçekçi gerçek zamanlı ışıklandırma elde etmek için Işık Problarına ihtiyacınız var.

Room GameObject'inin alt öğesi olarak yeni bir Işık Probu Grubu eklemek: Hiyerarşi penceresinde, "Room_[style]" GameObject'ine sağ tıkladık ve "Light > Light Probe Group"u seçtik.

Işık problarını düzenleyebilmek için: Sahne görünümünün sağ üst köşesinde 3B Simgeli Gizmo'lar seçeneğinin etkinleştirildiğinden emin olduk. "Light Probe Group" seçiliyken, "Tools" katmanındaki "Edit Light Probe Group" düğmesini seçtik.

Işık problarını çoğaltın ve odanın etrafında yeniden konumlandırmak: Probların etrafındaki seçim kutularını sürükleyerek probları seçtik. Probu konumlandırmak için "Move" aracını kullandık. Seçili probları çoğaltmak için Ctrl+D (macOS: Cmd+D) tuşlarını kullandık. Not: Sahne görünümünün sağ üst köşesindeki eksen gizmosunun altındaki simgeyi seçerek İzometrik görünüme geçmek faydalı olabilir.

Işık problarınızı doğru şekilde konumlandırmak için: Problarınızı, ışığın rengi veya yoğunluğu açısından önemli değişikliklerin olduğu alanlara yerleştirdiğinizden emin olun. Problarınızın GameObject'lerin içinde olmadığından emin olun.

Işık problarınızın etkisini görün: "Lighting" penceresinden ışıklandırmanızı yeniden oluşturun ve dinamik GameObject'lerinizdeki ışıklandırmayı test edin.

Aydınlatmayı Tamamlamak

Aydınlatma ayarlarınızı kabaca istediğiniz gibi yapılandırdıktan sonra, artık daha kesin ve yüksek çözünürlüklü bir ışık haritası hazırlayabilirsiniz.

Aydınlatma ayarlarınızın hedef cihazınız için uygun şekilde optimize edildiğinden emin olmak: Uygulamanızı, kullanıcıların kullanmasını beklediğiniz şekilde test edin (diğer bir deyişle, hedef kitleniz mobil cihazlarsa, uygulamayı bilgisayarınıza bağlı olmayan bağımsız bir cihazda test edin). Hedef kare hızına ulaştığınızdan emin olun. Uygulamanızı gerçek cihazda derleme ve çalıştırma talimatları için VR Proje Kurulumu öğreticisindeki talimatlara bakın.

Birkaç küçük dosya yerine tek bir ışık haritası dosyası oluşturmak: "Lighting" penceresinde, açılır menüyü (üçgen) kullanarak "Lightmapping Settings" bölümünü genişlettik. "Max Lightmap Size" Boyutu özelliğini 4096 olarak ayarladık. Birkaç küçük dosya yerine tek bir ışık haritası dosyasına sahip olmanız önerilir.

Lekeli veya pikselli gölgeler alıyorsanız: "Lightmap Compression" özelliğini "None" olarak ayarlayın.

Işıklandırmanızın genel görünümünden memnunsanız ve son ışık haritanızı oluşturmaya hazırsanız: "Lightmap Resolution" özelliğini 20 ile 80 arasında bir değere yükseltin. İsterseniz, istediğiniz sonucu elde etmek için diğer ışıklandırma ayarlarını (örnekler, yansımalar vb.) ayarlamaya devam edin.

Işıklandırmanız artık istediğiniz gibi görünmeli ve performans açısından optimize edilmiş olmalıdır.

    Projeye Özel Scriptler

    Scanner

    XR Interaction Toolkit içinde yer alan bir scripti miras alan kendi kodumuzu uygulamada yer alan nesnelerin adlarını ve konumlarını tarayan bir tarayıcı (scanner) gameobject kurmak için kullanacağız. 

    using UnityEngine;
using UnityEngine.XR.Interaction.Toolkit; // XRGrabInteractable, SelectEnterEventArgs, SelectExitEventArgs, ActivateEventArgs, DeactivateEventArgs, HoverEnterEventArgs, HoverExitEventArgs
using UnityEngine.XR.Interaction.Toolkit.Interactables;// miras aldığımız sınıf için gerekli
using TMPro;

public class Scanner : XRGrabInteractable // XRGrabInteractable sınıfından miras alarak, bu sınıfın özelliklerini kullanarak bir tarayıcı oluşturuyoruz
{
    [Header("Scanner Settings")]
    public Animator animator;
    public LineRenderer laserRenderer;
    public GameObject body;
    private Color originalBodyColor;
    public TextMeshProUGUI targetName;
    public TextMeshProUGUI targetPosition;
    private bool isSelect;
    private bool isActivated;
    private GameObject lastHitObject;
    private Color lastColor;
    protected override void Awake() // Awake() metodu, nesne oluşturulduğunda bir kez çağrılır. Bu metotta, tarayıcının başlangıç durumunu ayarlıyoruz.
    {
        base.Awake(); // base.Awake() çağrısı, XRGrabInteractable sınıfının Awake() metodunu çağırarak, bu sınıfın özelliklerini kullanmamızı sağlar. bunu kullanmazsak overrade ettiğimiz metodun içindeki orijinal kodlar çalışmaz.
        ScanerActiveted(false);
    }
    private void Start()
    {
        Renderer renderer = body.GetComponent<Renderer>();
        originalBodyColor = renderer.material.color;
        isSelect = false;
    }
    protected override void OnSelectEntered(SelectEnterEventArgs args) // OnSelectEntered() metodu, nesne seçildiğinde çağrılır.
    {
        base.OnSelectEntered(args);
        animator.SetBool("Opened", true); 
        isSelect = true;
        ChangeHoverColor(false);
    }
    protected override void OnSelectExited(SelectExitEventArgs args) // OnSelectExited() metodu, nesne seçimi bırakıldığında çağrılır.
    {
        base.OnSelectExited(args);
        animator.SetBool("Opened", false);
    }

    protected override void OnActivated(ActivateEventArgs args) // OnActivated() metodu, nesne etkinleştirildiğinde çağrılır. Bu metotta, tarayıcının lazerini ve hedef bilgilerini gösteriyoruz.
    {
        base.OnActivated(args);
        ScanerActiveted(true);
    }
    protected override void OnDeactivated(DeactivateEventArgs args) // OnDeactivated() metodu, nesne devre dışı bırakıldığında çağrılır. Bu metotta, tarayıcının lazerini ve hedef bilgilerini gizliyoruz.
    {
        base.OnDeactivated(args);
        ScanerActiveted(false);
        OldMaterial();
    }
    protected override void OnHoverEntered(HoverEnterEventArgs args) // OnHoverEntered() metodu, nesne üzerine gelindiğinde çağrılır. Bu metotta, tarayıcının rengini değiştiriyoruz.
    {
        base.OnHoverEntered(args);
        if (!isSelect)
            ChangeHoverColor(true);
    }
    protected override void OnHoverExited(HoverExitEventArgs args) // OnHoverExited() metodu, nesne üzerinden ayrıldığında çağrılır. Bu metotta, tarayıcının rengini eski haline getiriyoruz.
    {
        base.OnHoverExited(args);
        if (!isSelect)
            ChangeHoverColor(false);
    }
    private void ChangeHoverColor(bool isOriginal) // ChangeHoverColor() metodu, tarayıcının rengini değiştirmek için kullanılır. isOriginal parametresi, rengin orijinal mi yoksa yeni mi olduğunu belirtir.
    {
        Renderer renderer = body.GetComponent<Renderer>();
        if (isOriginal)
            renderer.material.color = Color.red;
        else
            renderer.material.color = originalBodyColor;
    }
    private void ScanerActiveted(bool isActivated) // ScanerActiveted() metodu, tarayıcının lazerini ve hedef bilgilerini göstermek veya gizlemek için kullanılır. isActivated parametresi, tarayıcının etkinleştirilip etkinleştirilmediğini belirtir.
    {
        laserRenderer.gameObject.SetActive(isActivated);
        targetName.gameObject.SetActive(isActivated);
        targetPosition.gameObject.SetActive(isActivated);
        this.isActivated = isActivated;
    }
    private void ScanForObject() // ScanForObject() metodu, tarayıcının lazerini kullanarak bir nesne taramak için kullanılır. Raycast kullanarak, lazerin yönünde bir nesne olup olmadığını kontrol ederiz ve eğer varsa, hedef bilgilerini güncelleriz.
    {
        RaycastHit hit;

        Vector3 worldHit = laserRenderer.transform.position + laserRenderer.transform.forward * 1000f;

        OldMaterial();


        // Raycast kontrolü
        if (Physics.Raycast(laserRenderer.transform.position, laserRenderer.transform.forward, out hit))
        {
            worldHit = hit.point;

            targetName.SetText(hit.collider.name);
            targetPosition.SetText(hit.collider.transform.position.ToString());

            Renderer newRenderer = hit.collider.GetComponentInParent<Renderer>();

            if (newRenderer != null)
            {
                lastHitObject = newRenderer.gameObject;
                lastColor = newRenderer.material.color;

                newRenderer.material.color = Color.green;
            }
        }

        // Lazer ucu çizimi (local space dönüşüm)
        laserRenderer.SetPosition(
            1,
            laserRenderer.transform.InverseTransformPoint(worldHit)
        );
    }
    public override void ProcessInteractable(XRInteractionUpdateOrder.UpdatePhase updatePhase) // ProcessInteractable() metodu, her frame çağrılır. Bu metotta, tarayıcının lazerini sürekli olarak güncelliyoruz.
    {
        base.ProcessInteractable(updatePhase);
        if (isActivated)
        {
            ScanForObject();
        }
    }

    void OldMaterial() // Önce eski objeyi eski rengine döndür
    {
        if (lastHitObject != null)
        {
            Renderer oldRenderer = lastHitObject.GetComponentInParent<Renderer>();

            if (oldRenderer != null)
            {
                oldRenderer.material.color = lastColor;
            }

            lastHitObject = null;
        }
    }
}

    Trigger Value Okumak

    using UnityEngine;

// XR Interaction Toolkit ana namespace
using UnityEngine.XR.Interaction.Toolkit;

// Interactor sınıfları burada
using UnityEngine.XR.Interaction.Toolkit.Interactors;

/// <summary>
/// Trigger değerini her frame okuyup konsola yazdırır.
/// XRGrabInteractable'dan inherit aldığı için
/// obje grab edilebilir hale gelir.
/// </summary>
public class TriggerValue : XRGrabInteractable
{
    [Header("Debug")]

    // Inspector üzerinden anlık trigger değerini görmek için
    public float currentTriggerValue;

    // Objeyi şu an hangi interactor'ın tuttuğunu saklar
    // (sağ el / sol el / simulator controller)
    private XRBaseInputInteractor m_InputInteractor;

    /// <summary>
    /// Obje grab edildiğinde otomatik çalışır.
    /// </summary>
    protected override void OnSelectEntered(SelectEnterEventArgs args)
    {
        // Parent class'ın kendi grab işlemlerini çalıştır
        base.OnSelectEntered(args);

        // Objeyi grab eden interactor'ı al
        // "as" kullanımı güvenli cast sağlar
        m_InputInteractor = args.interactorObject as XRBaseInputInteractor;

        // Debug bilgisi
        Debug.Log("Grab başladı: " + m_InputInteractor?.gameObject.name);
    }

    /// <summary>
    /// Obje bırakıldığında otomatik çalışır.
    /// </summary>
    protected override void OnSelectExited(SelectExitEventArgs args)
    {
        // Parent class'ın kendi bırakma işlemlerini çalıştır
        base.OnSelectExited(args);

        Debug.Log("Grab bitti");

        // Referansı temizle
        // Böylece artık input okumaya çalışmaz
        m_InputInteractor = null;
    }

    /// <summary>
    /// XR sisteminde her frame çağrılır.
    /// Input okumak için en uygun yerlerden biridir.
    /// </summary>
    public override void ProcessInteractable(XRInteractionUpdateOrder.UpdatePhase updatePhase)
    {
        // Parent class'ın kendi update işlemleri çalışsın
        base.ProcessInteractable(updatePhase);

        // Eğer obje tutulmuyorsa çık
        if (!isSelected)
            return;

        // Eğer interactor yoksa çık
        if (m_InputInteractor == null)
            return;

        // activateInput null mı kontrol et
        // Bazı XR setup'larında eksik olabilir
        if (m_InputInteractor.activateInput == null)
        {
            Debug.LogWarning("activateInput NULL!");
            return;
        }

        // Trigger değerini oku
        // Analog controller:
        // 0.0 → 1.0 arası değer verir
        //
        // Mouse/klavye:
        // genelde sadece 0 veya 1 verir
        float triggerValue =
            m_InputInteractor.activateInput.ReadValue();

        // Inspector'da görmek için kaydet
        currentTriggerValue = triggerValue;

        // Konsola anlık yazdır
        Debug.Log("Trigger Value: " + triggerValue);
    }
}
